# Parallax

SillyTavern 扩展：让模型用它最擅长的语言写正文，读的时候看简体中文译文。

预设只要求模型用外语（主要是日语）写作。回复写完后，Parallax 用一次独立的模型调用把正文译成简体中文。**译文只进显示层**，消息本体保留原文，所以发给模型的上下文始终是原文。

## 特点

- **译文不进消息本体**：不改聊天记录，卸载或关闭后聊天就是原样。每楼可以一键在原文和译文之间切换。
- **只翻勾选的标签**：扫描最新一楼，勾选哪些标签里的文字要翻译。状态栏、面板、思维链等其余内容不会送去翻译，也不会被改动。勾选结果按预设各记一份。
- **译名表**：自己填「原文 = 译名」，表里有的照表翻译。分通用表和每张角色卡各自的表。
- **缺哪段补哪段**：正文按段落编号送翻，模型漏翻、截断时只补缺的段落；部分成功也先显示已翻好的。
- **swipe、编辑都跟得上**：每个 swipe 的译文各自保存，切回来不重翻；编辑后只重翻改过的段落。
- **导出译文**：把整个聊天里 AI 楼的译文存成一个 txt，可以选导出哪些标签里的内容、要不要每楼加「第N章」小标题；导出前可以一键把没翻的楼补翻完。
- **只做翻译**：不润色、不改写。

## 安装

在酒馆的「扩展 → 安装扩展」里填入本仓库地址。

## 使用

1. 魔杖菜单里点 **Parallax** 打开面板。
2. 「设置」页选好翻译用的模型连接（酒馆当前连接 / 连接配置 / 独立 API）。
3. 让预设生成一楼，回到「首页」点「扫描最新一楼」，勾上正文所在的标签。
4. 之后每次回复写完会自动翻译。每楼消息的按钮区有一个小按钮，可以切换原文和译文，或者手动翻译这一楼。

译法是内置的，按「设置」页选的原文语言自动选用（目前支持日语）。

## 说明

- 开场白、手动停止的回复不会自动翻译，可以用每楼按钮手动翻。
- 译文保存在聊天文件里每条消息的附加数据中。「设置」页可以清除当前聊天的全部译文。
- 每次翻译会多花一次模型调用；一楼原文超过「每批原文字符数上限」（设置页，默认 20000）时会分成几批，每批一次调用。
- 导出译文在「首页」最下面，导出本身不调用模型。没翻译过的楼会用原文并标出来；「翻译所有没翻的楼」会一楼一楼排队翻，每楼至少一次模型调用。
- 给模型留的输出长度跟着预设的「最大回复长度」走，不低于 50000。
